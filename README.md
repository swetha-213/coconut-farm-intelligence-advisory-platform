# 🌴 Coconut Farm Intelligence & Advisory Platform

> An intelligent decision-support platform designed to assist coconut farmers with data-driven insights for crop health, yield estimation, farm management, and agricultural decision-making.

## 📌 Overview

The **Coconut Farm Intelligence & Advisory Platform** is a software-based agricultural solution developed to support farmers in making informed decisions throughout the farming process.

The system combines **Python, Flask, Machine Learning, and database technologies** to provide features such as crop disease detection, yield prediction, agricultural data management, and an intelligent farmer assistance module.

The main goal of this project is to reduce manual decision-making and provide farmers with accessible, technology-driven agricultural support.

## 🎯 Objectives

* To assist farmers in identifying crop diseases using image-based analysis.
* To predict agricultural yield using Machine Learning techniques.
* To provide data-driven insights for farm management.
* To assist farmers with common agricultural queries.
* To organize and manage farming-related information digitally.
* To develop an easy-to-use platform for technology-assisted farming.

## ✨ Key Features

### 🌿 Crop Disease Detection

Analyzes crop/leaf images using a trained Machine Learning model to identify potential diseases.

### 📊 Yield Prediction

Uses agricultural data and a trained Machine Learning model to estimate expected crop yield.

### 🤖 Farmer Assistance

Provides an intelligent assistance module to help users with farming-related queries and information.

### 🌱 Farm Data Management

Allows farming-related information to be organized and managed digitally.

### 📋 Agricultural Decision Support

Combines available agricultural data and Machine Learning predictions to support better farming decisions.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/swetha-213/coconut-farm-intelligence-advisory-platform.git
```

### 2. Navigate to the project directory

```bash
cd coconut-farm-intelligence-advisory-platform
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Open the local URL displayed in the terminal to access the application.

## 📋 Requirements

Make sure the following are installed before running the project:

* Python 3.x
* pip
* Required Python packages listed in `requirements.txt`
